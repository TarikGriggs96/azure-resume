About me

The engineer teams call when it's on fire

I'm a Senior Cloud Support Engineer at Cloud at Work, where I'm the subject matter expert and escalation owner for hosted private-cloud and Microsoft Azure environments. I own high-impact incidents from first alert through resolution and the follow-up that comes after.

Over 7+ years across cloud infrastructure, Azure, Microsoft 365, and systems administration, I've learned that fixing the ticket is only half the job. I look for the trend behind the tickets, drive the fix that stops repeats, and explain the root cause to clients in plain language.

I also lead a team of four L3 engineers: coaching them on complex cases, planning workload and priorities, and building the runbooks and training that help new engineers get up to speed.

In progress · Cloud Resume Challenge

A serverless resume on Azure

This site is my take on the Cloud Resume Challenge. It's served as a static website from Azure Storage, and a visitor counter at the bottom of the page calls an Azure Functions API that reads and updates a count in Cosmos DB.

The infrastructure is defined as code with Bicep and deployed by GitHub Actions, so every change goes through source control and a pipeline instead of the Portal.
